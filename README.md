# HR Analysis Dashboard (Power BI)

An interactive, end-to-end **HR Analysis Dashboard** built in Microsoft Power BI. This project transforms raw human resources data into an executive-level tracking tool designed to analyze employee demographics, performance, pay scales, and critical attrition patterns.

## 🔍 Key Business Insights & Questions Answered

This dashboard serves as a central tool for HR business partners and executive leadership to answer core organizational questions:

* **Workforce Footprint Overview:**
  * Tracks high-level indicators: **1.48K total employees**, an average monthly income of **\$6.50K**, an average performance rating of **3.15**, and an average salary hike of **15.21%**.
* **Targeted Attrition Risks:**
  * Breaks down attrition by age group, highlighting that the **26–35 demographic accounts for 48.74% of all employee turnover**, calling for refined mid-level retention strategies.
  * Details how attrition relates directly to specific job roles and fields.
* **Employee Sentiment & Job Satisfaction:**
  * Monitors internal satisfaction distributions showing that **39.59%** of the workforce reports top-tier job satisfaction, while mapping out smaller, dissatisfied categories for proactive HR intervention.
* **Talent Pipeline Demographics:**
  * Identifies the primary academic backgrounds feeding the organization, showing **Life Sciences (41.01%)** and **Medical (31.76%)** fields as major recruiting channels.
* **Compensation Curves & Hourly Rates:**
  * Graphs the average hourly rate trends across distinct job roles, providing clear comparisons between entry-level roles, specialized researchers, sales executives, and directors.

## 🛠️ Tech Stack & Skills Demonstrated

* **Business Intelligence Engine:** Microsoft Power BI Desktop
* **Data Transformation & ETL:** Power Query (cleaning text inputs, grouping age distributions, and shaping table structures)
* **Analytical Modeling:** DAX (Data Analysis Expressions) for dynamic KPIs, headcount aggregations, and specialized breakdown percentages.
* **UI/UX Design:** Implemented functional side-panel filtering systems for deep-dives based on **Department** and **Gender**, utilizing clean corporate visual layouts.

## 🚀 How to Open and Explore the Project

1. **Prerequisites:** Ensure you have the latest version of [Microsoft Power BI Desktop](https://microsoft.com) installed.
2. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```
3. **Open Report:** Navigate to the folder and open the `HR_Analysis.pbix` file.
4. **Interact:** Click through the **Department** and **Gender** filters on the left panel to see metrics update dynamically across all charts.
